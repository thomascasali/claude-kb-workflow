# Code of Conduct

> Versione semplificata, adattata dal [Contributor Covenant 2.1](https://www.contributor-covenant.org/).

## Il nostro impegno

Vogliamo che questo progetto sia un ambiente accogliente per chiunque, indipendentemente da età, esperienza tecnica, identità di genere, orientamento, etnia, religione, nazionalità o livello professionale.

## Comportamenti incoraggiati

- 🤝 Essere rispettosi e pazienti
- 💡 Dare feedback costruttivi
- 🎓 Aiutare chi è alle prime armi
- 🙏 Accettare critiche con apertura
- 🌍 Considerare il punto di vista altrui

## Comportamenti inaccettabili

- ❌ Linguaggio offensivo, sessista, razzista
- ❌ Attacchi personali, trolling, insulti
- ❌ Molestie pubbliche o private
- ❌ Pubblicare info private altrui senza consenso
- ❌ Spam o autopromozione aggressiva

## Ambito

Questo Code of Conduct si applica a:
- Issue, Pull Request, Discussion su GitHub
- Commit message e commenti nel codice
- Qualsiasi comunicazione legata al progetto

## Enforcement

Comportamenti inaccettabili possono essere segnalati ai maintainer. Le azioni includono:
- **Warning**: avviso privato
- **Temporary ban**: divieto temporaneo di interazione
- **Permanent ban**: rimozione permanente dal progetto

I maintainer si impegnano a essere imparziali. Le decisioni vengono prese in privato per proteggere chi segnala.
