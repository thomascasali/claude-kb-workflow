# scripts/lib/secret-scope.txt — inclusioni/esclusioni di REGOLA per PATH, per
# scripts/lib/secret-scan.sh (letto dallo scanner: vale per ogni chiamante,
# incluso .githooks/pre-commit).
#
# Formato: GLOB<TAB>AZIONE<TAB>REGOLA
#   Il separatore è un carattere TAB.
#   GLOB     Pattern di shell (bash [[ == ]], "*" combacia anche con "/")
#            confrontato col path relativo alla radice del repo git oppure,
#            per una scansione fuori da un repo, col path assoluto del file.
#   AZIONE   EXCLUDE        sotto GLOB la REGOLA non scatta (resta attiva
#                           altrove).
#            INCLUDE_ONLY   la REGOLA scatta SOLO sotto GLOB, ed è
#                           disattivata ovunque altrove.
#   REGOLA   Nome esatto di una regola in secret-patterns.txt.
#
# Righe vuote e righe che iniziano per # sono ignorate.
#
# Esempio di EXCLUDE (tenuto commentato): skill o documenti di terze parti
# copiati nel repo, che parlano DI password e token senza contenerne uno
# vero, farebbero scattare la regola chiave=valore in massa. Le regole di
# FORMATO (prefissi di provider reali, chiavi PEM, JWT) restano attive
# ovunque. Togli il # e adatta il glob alla tua cartella:
#   vendor/skills/**<TAB>EXCLUDE<TAB>SECRET_ASSIGNMENT
#
# SECRET_ASSIGNMENT_PROSE è la regola larga per le note di memoria scritte
# in prosa ("- Password: ...", "il token è ..."): confinata alle cartelle
# di memoria, altrimenti la prosa ordinaria la farebbe scattare ovunque.
# I primi due glob coprono ~/.claude/projects/<id>/memory/; gli altri le
# cartelle di memoria dei progetti. wiki/projects/** e raw/** coprono la wiki
# di lavoro (note di progetto e sessioni grezze), dove le credenziali finiscono
# più facilmente scritte in prosa. Ogni cartella ha anche la forma "*/...", per
# le scansioni fuori da un repo e le sottocartelle di un repo.
*/projects/*/memory/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
projects/*/memory/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
memory/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
*/memory/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
project-memories/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
*/project-memories/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
wiki/projects/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
*/wiki/projects/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
raw/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
*/raw/**	INCLUDE_ONLY	SECRET_ASSIGNMENT_PROSE
